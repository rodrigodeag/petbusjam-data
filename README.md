# PetBusJam Data & Level Generator

Official repository for **PetBusJam** level data (`levels.json`) and procedural generator tools.

## Structure
- `levels.json`: Lightweight JSON consumed by the Godot 4 mobile client via GitHub Raw.
- `generator.py`: Python 3 script for procedural generation and validation of puzzle levels.

## Usage
Generate 100 levels:
```bash
python generator.py 100
```
